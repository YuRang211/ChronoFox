# ChronoFox (크로노폭스)

Windows 바탕화면에서 쓰는 로컬 우선(local-first) 개인 플래너입니다. 달력, 일정, 메모, 해야 할 일, 시계/알람을 한 앱 안에서 관리합니다.

크로노폭스는 Python `PySide6`로 만들었으며, 모든 데이터는 인터넷 연결 없이 내 컴퓨터에만 저장됩니다.

언어는 Windows 시스템 언어를 기준으로 처음 설정되며, 앱 안에서는 `설정 > 테마 > 언어`에서 한국어/영어를 바꿀 수 있습니다.

## 0.8.2 변경 사항

- 달력·트레이 메뉴의 여백과 투명도 제어 배치를 정리하고, 헤더 메뉴를 반복해서 열 때 객체가 누적되던 문제를 수정했습니다.
- 손상된 백업과 잘못된 설정값을 복원 전에 검사하고, 복원 중 파일 교체에 실패하면 기존 파일을 자동으로 되돌립니다. 자동 복구도 실패하면 저장을 차단하고 복구 백업 경로를 안내합니다.
- 복원 전에는 편집 중인 메모를 백업에 반영하고, 복원 후에는 대기 중이던 자동 저장이 복원본을 덮지 않도록 보호합니다.
- 복원 안내창의 다크 테마 가독성을 개선하고, 코드 주석을 현재 동작과 안전 계약 중심으로 정리했습니다.

소스 버전은 `0.8.2`입니다. 설치파일 제공 여부는 아래 Releases 페이지에서 확인하세요. 소스 push만으로 설치된 앱이 업데이트되지는 않습니다.

## 주요 기능

- **월간 달력**: 공휴일 표시(한국 공휴일, `holidays` 패키지 설치 시), 일요일/공휴일 강조, 날짜별 미리보기.
- **날짜별 노트/일정**: 날짜를 클릭하면 열리는 창에서 자유 텍스트 노트를 자동 저장하고, 시작/종료 시각과 색상이 있는 시간 일정(이벤트)을 추가할 수 있습니다. 시간 일정에는 시작 전 알림(정시/10분/30분/60분 전)을 설정할 수 있습니다.
- **스티커 메모**: 바탕화면에 띄워두는 메모 창으로, 마크다운으로 작성한 내용을 실시간 미리보기로 확인할 수 있습니다. 창 크기/위치는 껐다가 다시 열어도 유지됩니다.
- **해야 할 일**: 반복 주기(매일/매주 등)가 있는 할 일 목록. 목록별 분류, 검색/필터(나의 하루, 중요, 완료 등), 중요 표시(★), 마감일 설정을 지원합니다.
- **관리 탭**: 일/주 시간표와 월간 보기로 시간 일정을 한눈에 보고, 해야 할 일 목록과 보관한 메모도 같은 탭에서 확인할 수 있습니다.
- **시계**: 스톱워치, 타이머, 알람(요일 반복 또는 특정 날짜 1회, 스누즈, 알림 방식 선택)을 제공하며, 시간 탭에서 다음 알람 시각을 요약해 보여줍니다.
- **통합 검색**: 날짜 노트와 메모를 함께 검색해 원하는 항목으로 바로 이동합니다.
- **로컬 백업**: 설정, 일정, 노트, 해야 할 일, 메모를 zip 파일 하나로 내보내 백업/복원할 수 있습니다.
- **ICS 캘린더 내보내기**: 노트와 시간 일정을 표준 ICS 파일로 내보내 구글 캘린더, 아웃룩 등 다른 캘린더 앱으로 가져올 수 있습니다.
- **한국어/영어 언어 설정**, **라이트/다크 테마**: 설정 화면에서 언제든 전환할 수 있습니다.

## 설치

ChronoFox는 GitHub 저장소의 **[Releases 페이지](https://github.com/YuRang211/ChronoFox/releases)**에서 최신 버전을 내려받습니다. 설치 방법은 두 가지 중 편한 쪽을 고르면 됩니다.

### 방법 1 — 설치본 (`ChronoFox-Setup.exe`)

1. Releases 페이지에서 최신 버전의 `ChronoFox-x.y.z-Setup.exe`를 내려받습니다.
2. 실행 파일을 더블클릭해 설치 마법사를 진행합니다.
3. **관리자 권한이 필요 없는 개인 사용자용 설치**입니다(설치 위치: `%LOCALAPPDATA%\Programs\ChronoFox`). 시작 메뉴 바로가기가 자동으로 생기고, 바탕화면 아이콘은 설치 중 선택 옵션으로 켤 수 있습니다.
4. Windows **설정 > 앱 > 설치된 앱 > ChronoFox > 제거**로 삭제할 수 있습니다. 프로그램·바로가기·ChronoFox 자동실행 등록은 제거되지만 `%USERPROFILE%\.desktop_note_calendar`의 내 데이터(설정·일정·메모)는 그대로 남습니다.

### 방법 2 — 무설치(포터블 zip)

1. Releases 페이지에서 `ChronoFox-x.y.z-portable.zip`을 내려받습니다.
2. 원하는 폴더에 압축을 풉니다.
3. 압축을 푼 폴더 안의 `ChronoFox.exe`를 더블클릭해 바로 실행합니다. 별도 설치 과정이 없습니다.
4. 앱 데이터를 다른 PC로 옮기려면 포터블 프로그램 폴더가 아니라 `%USERPROFILE%\.desktop_note_calendar` 데이터 폴더를 새 PC의 같은 경로로 복사합니다(포터블 폴더 안 `README.txt`에도 같은 안내가 있습니다).

### 앱에서 업데이트 확인

`관리 > 설정 > 정보`에서 **업데이트 확인**을 누르면 현재 버전과 GitHub Releases의 새 버전을 비교합니다. 앱 시작이나 백그라운드에서는 자동으로 확인하지 않으며, 버튼을 누르기 전에는 업데이트용 인터넷 연결을 만들지 않습니다.

- 설치본은 **업데이트**를 누르면 Setup과 `SHA256SUMS.txt`를 내려받아 SHA-256을 확인하고, 사용자 데이터의 사전 백업을 만든 뒤 보이는 설치 마법사를 실행합니다.
- 포터블·소스 실행은 파일을 자동 교체하지 않고 공식 Releases 페이지만 엽니다.
- 인터넷 또는 업데이트 서버에 연결할 수 없으면 설정 화면에 다시 확인할 수 있는 안내가 표시됩니다.
- 이 기능이 처음 포함된 버전은 한 번 직접 설치해야 하며, 현재 개발 빌드는 코드 서명이 없어 실행 전 별도 경고가 표시됩니다.

### SmartScreen 경고가 뜨는 경우

ChronoFox는 아직 코드 서명이 되어 있지 않습니다. 그래서 처음 실행할 때 Windows SmartScreen이 "Windows에서 PC를 보호했습니다" / "알 수 없는 게시자" 경고를 보여줄 수 있습니다. 공식 Releases에서 내려받은 파일인지 먼저 확인한 뒤 아래 순서로 진행합니다.

1. 경고 창에서 **"추가 정보"**를 클릭합니다.
2. 표시된 앱 이름(ChronoFox)을 확인하고 **"실행"** 버튼을 클릭합니다.

배포 파일이 맞는지 더 확실히 확인하고 싶다면, Releases 페이지의 `SHA256SUMS.txt`로 무결성을 검증할 수 있습니다.

```powershell
# 내려받은 파일과 같은 폴더에서 실행
Get-FileHash .\ChronoFox-x.y.z-Setup.exe -Algorithm SHA256
# 결과 해시 값이 SHA256SUMS.txt에 적힌 값과 일치하는지 비교합니다.
```

## 첫 사용 흐름

1. **앱 실행**: 설치본이면 시작 메뉴에서, 포터블이면 `ChronoFox.exe`를 더블클릭해 실행합니다. 처음 실행 시 Windows 시스템 언어에 맞춰 한국어/영어가 자동으로 선택됩니다.
2. **달력에서 날짜 클릭**: 원하는 날짜를 클릭하면 노트/일정 창이 열립니다. 노트 탭에는 자유 텍스트를 적고(자동 저장), 일정 탭에서는 시작/종료 시각과 색상이 있는 시간 일정을 추가할 수 있습니다.
3. **알람 설정(시계 창)**: 우상단 메뉴(햄버거 아이콘) → **시계**를 열고 **알람** 탭에서 `알람 추가`를 누릅니다. 알람 이름, 반복 방식(요일 반복 또는 특정 날짜 1회), 알림 방식(팝업 / 윈도우 알림 / 소리만), 스누즈 시간, 알림음을 설정할 수 있습니다.
4. **트레이 아이콘 동작**: 창을 닫아도(X 버튼) 앱은 종료되지 않고 시스템 트레이에 상주합니다. 트레이 아이콘을 클릭/더블클릭하면 창을 다시 열 수 있고, 우클릭 메뉴에서 새 메모 만들기·설정·완전 종료를 바로 실행할 수 있습니다. 앱을 완전히 끝내려면 트레이 메뉴의 **종료**를 눌러야 합니다.
5. **관리 탭**: 우상단 메뉴 → **관리**에서 일/주/월 시간표로 시간 일정을 한눈에 보고, 같은 탭에서 해야 할 일 목록과 보관한 메모도 확인합니다.

그 외에도 우상단 메뉴에서 해야 할 일, 새 메모 만들기, 숨은 메모 불러오기, 설정으로 바로 이동할 수 있고, 헤더의 통합 검색으로 노트와 메모를 함께 찾아 이동할 수 있습니다.

## 데이터·백업

모든 데이터는 클라우드가 아닌 로컬에 저장됩니다.

- 설정/일정 데이터: `%USERPROFILE%\.desktop_note_calendar\config.json`, `%USERPROFILE%\.desktop_note_calendar\data.json`
- 메모 파일: `%USERPROFILE%\.desktop_note_calendar\Notes`

### 백업 만들기 / 복원

`설정 > 연동` 탭에서 진행합니다.

- **백업 만들기**: 설정, 일정, 노트, 해야 할 일, 메모를 zip 파일 하나로 내보냅니다.
- **백업 복원**: 이전에 만든 zip 백업 파일을 선택하면 저장 시각과 항목 수(일정/계획/반복 작업/알람/메모 개수)를 미리 보여주고, 복원을 확정하면 현재 데이터를 덮어씁니다. **복원 전 현재 상태는 자동으로 롤백용 백업이 만들어지므로**, 복원 중 문제가 생겨도 이전 상태로 되돌릴 수 있습니다. 복원한 내용은 크로노폭스를 다시 시작해야 적용됩니다.

### 개인정보 고지

**백업 zip 파일에는 일정·메모 등 개인 정보가 그대로 포함됩니다.** 백업 파일을 다른 사람과 공유하거나 클라우드/이메일 등에 업로드할 때는 반드시 주의하세요. (앱 내 백업/복원 다이얼로그에도 같은 안내가 표시됩니다.)

## 개발자용 (소스에서 실행)

1. VS Code(또는 원하는 터미널)에서 이 폴더를 엽니다.
2. 터미널에서 아래 명령을 실행합니다.

```powershell
python -m pip install PySide6
python .\desktop_note_calendar.py
```

공휴일 표시를 사용하려면 `holidays` 패키지를 추가로 설치합니다(선택 사항, 없어도 앱은 정상 동작합니다).

```powershell
python -m pip install holidays
```

### 테스트

```powershell
python -m pytest -m "not slow" -q
```

`slow` 마커가 붙은 무거운 테스트까지 포함한 전체 스위트는 병합 전에 별도로 실행합니다(자세한 내용은 프로젝트 내부 문서 참고).

### 릴리스 빌드

로컬 PowerShell 파이프라인으로 설치본/포터블 zip/체크섬을 한 번에 만듭니다(ruff → 테스트 → PyInstaller → Inno Setup → zip → SHA256 순서, 실패 시 중단).

```powershell
.\build_release.ps1
```

`git push`만으로 사용자의 앱이 업데이트되지는 않습니다. 새 버전은 GitHub Release를 게시하고, 같은 Release에 `ChronoFox-x.y.z-Setup.exe`와 `SHA256SUMS.txt`를 각각 하나씩 올려야 앱에서 활성화됩니다. 버전을 올릴 때는 `APP_VERSION`, Inno Setup 기본 버전, `build_release.ps1` 기본값, `version_info.txt`를 함께 맞춥니다. 아래 명령은 빌드 없이 이 계약만 검사합니다.

```powershell
.\build_release.ps1 -ValidateVersionOnly
```

Inno Setup(`iscc.exe`)이 설치되어 있지 않으면 설치본 생성 단계는 건너뛰고 포터블 zip과 체크섬만 만듭니다. 산출물은 `.\out\release\`(포터블 zip, `SHA256SUMS.txt`)와 `.\installer\Output\`(설치본)에 생성됩니다.

코드 서명 인증서가 준비된 릴리스 PC에서는 인증서 지문을 넘기면 `ChronoFox.exe`, 설치본, 내장 제거 프로그램을 함께 서명합니다. 인증서나 비밀키는 저장소에 넣지 않습니다.

```powershell
.\build_release.ps1 -SignCertificateThumbprint "인증서의 40자리 SHA-1 지문"
```

`signtool.exe`를 자동으로 찾지 못하면 Windows SDK의 실행 파일 경로를 `-SignToolPath`로 함께 지정합니다. 인증서 지문을 생략한 일반 빌드는 현재와 같이 unsigned로 생성됩니다. 실제 배포 전에는 파일 속성의 디지털 서명 상태와 `SHA256SUMS.txt`를 모두 확인해야 합니다.
